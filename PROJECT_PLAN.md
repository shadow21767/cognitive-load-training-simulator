# Project Development Plan

## Phase 1 — MVP
- Timed label-matching task
- Five difficulty levels
- Accuracy tracking
- Response-time tracking
- Cognitive-load self-report
- SQLite persistence
- Analytics dashboard

## Phase 2 — Human Factors Features
- Stroop interference
- Secondary memory task
- Notification distractions
- Task switching
- Heatmap / click telemetry

## Phase 3 — Research Layer
- Participant consent screen
- Study condition randomization
- Anonymous participant IDs
- Statistical testing
- Effect-size calculations
- Exportable research dataset

## Phase 4 — Healthcare Simulation Extension
- Build a Unity/C# training scene
- Record user interactions
- Send session telemetry to the analytics service
- Compare novice vs. experienced-user performance

## Resume-ready framing

**Cognitive Load Training Simulator — Python, Streamlit, SQLite**

Developed a human-factors research prototype that measures task accuracy,
response time, error frequency, and perceived cognitive load across adaptive
difficulty levels. Implemented experiment telemetry, persistent session
logging, and an analytics dashboard for evaluating performance trends.
